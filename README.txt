========================================================================
             WIKIMASTERS AUTO-CLAIMER -- GUIDE DE DEMARRAGE
========================================================================

Bienvenue ! Voici comment lancer le logiciel sur votre ordinateur :

ETAPE 1 - INSTALLATION INITIALE (UNE SEULE FOIS)
   - Double-cliquez sur "installer.bat"
   - Le script installe les dependances Python necessaires en ~2 minutes.
   - Si Python n'est pas installe : https://www.python.org/downloads/
     (cochez "Add python.exe to PATH" lors de l'installation !)

ETAPE 2 - LANCEMENT DU LOGICIEL
   - Double-cliquez sur "lancer_interface.bat"
   - L'interface de WikiMasters Auto-Claimer s'ouvre.

ETAPE 3 - AJOUTER VOTRE COMPTE
   - Cliquez sur le bouton "+ Ajouter un compte"
   - Donnez-lui un nom (ex: "Mon Compte")
   - Choisissez "Creer un nouveau compte" ou "Connecter un compte existant"
   - Chrome s'ouvre avec votre propre profil 100% independant
   - Connectez-vous sur WikiMasters puis cliquez sur "J'ai fini"
   - Votre compte est immediatement pret et commence les tirages !

ETAPE 4 - MISES A JOUR AUTOMATIQUES
   - Vous n'avez RIEN a faire !
   - A chaque demarrage, le logiciel verifie automatiquement les mises a jour
     et les installe en quelques secondes.
   - Vos cookies de connexion et vos comptes ne sont JAMAIS supprimes.

VOS DONNEES RESTENT PRIVEES
   - Vos profils Chrome (cookies, sessions) restent uniquement sur votre PC.
   - Personne d'autre n'y a acces.

Amusez-vous bien !
